# 班务管理系统

一个面向班主任的班级成绩记录与评语管理工具，帮助教师高效完成学生成绩录入、统计分析、期末评语撰写等工作。

## 体验地址

https://class-management-system-r22i0tacg5.zh-cn.edgeone.cool/

## 功能特性

### V1.0 成绩录入 ✅

- **快速录入成绩** - 通过 pinyin-pro 库实现拼音模糊匹配，快速定位学生
- **回车键提交** - 输入分数后按回车自动提交，自动聚焦回姓名输入框
- **Excel 导出** - 支持将成绩导出为 Excel 文件，方便拷贝与分享
- **自定义导入** - 支持导入自定义学生名单
- **数据持久化** - 浏览器本地存储，刷新页面数据不丢失

### V2.0 期末评语 ✅

- **评语录入** - 支持手动输入评语或从 Excel 导入
- **个性化配置** - 支持设置字体大小、落款签名、页面纸张类型（A3/A4/B3/B4）
- **PDF 导出** - 一键导出评语为 PDF 格式
- **综合评比率** - 实时统计综合评分
- **图片导出** - 支持导出低分学生名单为图片，方便发送到班级群

### V3.0 UI 改版 + 设置中心 ✅

- **左侧菜单导航** - 全新侧边栏菜单交互模式
- **主题切换** - 4 种主题颜色（清新绿、阳光橙、优雅紫、柔和蓝粉）

- **设置页面** - 五大功能模块
  - **学生信息管理** - 增删改学生、批量打标签、标签编辑
  - **标签维护** - 灵活管理标签分类与标签项，支持 AI 生成标签
  - **单元配置** - 动态添加/删除成绩列（支持期末、期中、月考等）
  - **AI 配置** - 支持 Gemini、OpenAI 兼容 API
  - **系统备份** - 完整数据导出/导入，数据差异对比

- **成绩录入增强**
  - 多列成绩管理（期末、期中、月考等）
  - 分数统计：平均分、及格率、优秀率
  - 按分数区间筛选导出

- **期末评语增强**
  - 快捷评语 - 利用学生标签快速生成个性化评语
  - 个性化配置 - 字体大小、落款签名、纸张类型（A3/A4/B4）
  - PDF 导出

- **标签系统**
  - **学生标签管理** - 支持为学生添加多维度标签
  - **批量快速标记** - 支持逐个学生快速打标签
  - **标签分类维护** - 灵活管理标签分类与具体标签项

## 技术栈

| 类别     | 技术                                  |
| -------- | ------------------------------------- |
| 框架     | Vue 3.3 (Composition API)             |
| 构建工具 | Vite 5                                |
| 语言     | TypeScript 5.3                        |
| UI 组件  | Element Plus, VxeTable                |
| 状态管理 | Pinia                                 |
| 数据库   | Dexie (IndexedDB 封装)                |
| 样式     | Tailwind CSS 4, SCSS                  |
| 工具库   | xlsx, jsPDF, dom-to-image, pinyin-pro |
| 图标     | FontAwesome                           |
| AI 集成  | Gemini (Google), Doubao (字节)        |

## 数据说明

### 学生数据存储

- 学生数据存储在浏览器 localStorage 中
- 数据结构示例：
  ```json
  {
    "xing4_ming2": "张三",
    "yu3_wen2": 85,
    "shu4_xue2": 92,
    "comment": "该生学习认真...",
    "tags": { "优点": ["认真", "积极"] }
  }
  ```

### 表头配置

- 首列固定为 `xing4_ming2`（姓名），不可删除
- 其他列可通过设置页面动态添加、删除、排序

## 开发指南

### 添加新的分数列

1. 进入「设置」页面
2. 在「单元配置」中添加新列（输入列名，自动转换为拼音属性名）
3. 在「成绩录入」页面选择对应的列进行录入

### 导出成绩

1. 进入「成绩录入」页面
2. 点击统计卡片上的下载按钮
3. 选择导出格式（Excel 总表 / 按分数区间分 Sheet）

### 批量打印评语

1. 进入「期末评语」页面
2. 配置页面类型、落款等信息
3. 点击「导出 PDF」按钮
