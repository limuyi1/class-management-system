# 服务器 AI、累计额度与人工审核

2026-10-07，当前 schema v10。普通账号默认 PLATFORM，不填写个人 Key；管理员在「平台 AI 与额度」配置模型，给账号分配累计额度。输入与输出均计费，不按月重置。追加/扣减可用余额须填原因，保留审计和流水。个人可保存 Key 并明确选择 PERSONAL，个人模式不扣平台额度；任一模式失败均不自动换用另一模式。

管理员本人无个人 AI、平台配置前置及额度列表/弹窗改造见 [V5.0 完整迁移修正方案](./v5-server-parity-plan.md)。这些新约束待审核、未实施，不能按本文现有接口清单认定已完成。

## 配置和身份

支持 OpenAI 兼容 Chat Completions 及 Gemini REST。个人服务地址/接口类型首版须与管理员平台配置相同，个人可指定模型和 Key。Key 在服务器使用 AES-256-GCM 加密，不返回密文或明文；响应只展示是否已配置。`AI_ENCRYPTION_KEY` 为 32 字节随机值的标准 Base64，与数据库备份分开保存，恢复原库须使用匹配密钥。也可手动生成：

```bash
python3 -c 'import secrets,base64; print(base64.b64encode(secrets.token_bytes(32)).decode())'
```

服务器首次启动在未设置 `AI_ENCRYPTION_KEY` 时，自动生成数据库同目录下的 `.ai-encryption-key` 文件（仅当前用户读写），重启复用。可通过 `AI_ENCRYPTION_KEY_FILE` 指定独立持久路径；请单独备份此文件，不提交 Git。环境变量 `AI_ENCRYPTION_KEY` 优先，可保存到 `server/.env`。已有密文但找不到原主密钥时生成新主密钥并记录提示，原密文不变，后端继续启动。配置编辑页显示密钥无法读取，可重新填写 API Key 保存；也可恢复原主密钥后重启读取旧配置。本版本不提供在线密钥轮换。管理员只需在页面配置模型 API Key。

完整代管使用 `X-Managed-Session`，成绩、标签、默认生成要求、个人模型配置和额度均取目标有效用户，审计保留真实 actor。代管期间拒绝平台配置和额度分配等管理员能力。旧 `X-Managed-Account-Id` 仍不能用于个人身份/密钥接口。此前“始终使用真实 actor 的 AI 与额度”已由完整代管实现替代。

## 调用流程

1. 前端提交场景、提示要求、工作区/图片版本及稳定 Idempotency-Key，不提交用量或任意外部图片 URL。
2. 后端校验 actor/owner、业务关系和版本，读取成绩事实及账号默认提示。成绩识别图片从受保护的素材存储读取。
3. 建立持久调用记录，平台模式短事务预占预算，再在事务之外访问模型。同键同内容返回既有调用，重复点击/网络重试不会重复付费；换内容须使用新键。
4. 供应商返回整数输入、输出用量后结算，未用预算退回。生成结果先显示给教师审核，不自动覆盖成绩或评语。
5. 超时、中断、缺少用量或超预算均标记 UNCERTAIN，保留预占，禁止猜测零消耗。管理员查看近期调用，凭供应商账单填写实际用量和原因；超预算可补扣可用余额，不足须先追加额度。确认零消耗才释放。已有结果核对完成后可查询并审核使用。

每个操作者同时最多一笔，全局最多五笔；每小时最多创建 60 笔。HTTPS 443、公网 DNS 地址检查、固定连接 IP 和原域名 TLS 校验、禁止跟随重定向、DNS 15 秒、请求 120 秒、响应 4 MB 限制均在服务端执行。输入事实最多 100 KB，输出最多 4096 Token；视觉调用额外预占 32768 Token。预算偏保守，实际结算仍按供应商回报，不应把预占误当实际消耗。

取消请求会中断网络，但不能证明供应商没有收费，按待核对处理。服务重启把残留 RUNNING 转为 UNCERTAIN，不自动重试付费请求或释放额度。客户端断线后用原键重试或查询调用记录。

## 业务入口

当前服务器面板「分析、导入与高级工具」提供单人评语/润色、标签建议、学情分析、图片成绩识别、AI 批量评语及学习报告正文。该面板为当前实现，后续按完整迁移修正方案恢复原 V5.0 入口，不作为最终菜单设计。批量评语每批最多 50 人，逐人串行、可停止，失败保留成功项及原请求键；审核后整批保存成功项。

保存评语使用生成前捕获的评语版本，期间其他设备改写会冲突。成绩识别 JSON 可人工修正；后端核对学生及测评，并使用生成前捕获的单元格版本形成导入预览。任何版本冲突整批回滚。标签建议由教师核实后在标签页维护，不自动改写分类。

## 接口

| 接口                                             | 用途                                   |
| ------------------------------------------------ | -------------------------------------- |
| GET `/me/ai`，PUT `/me/ai/config`、`/me/ai/mode` | 本人配置和使用方式                     |
| GET/PUT `/admin/ai/config`                       | 管理员统一配置                         |
| POST `/admin/users/:id/ai-quota`                 | 累计余额调整，版本、幂等键及原因       |
| POST `/ai/calls`，GET `/ai/calls/:id`            | 创建/重试及查询本人调用                |
| POST `/ai/calls/cancel`                          | 按原请求键取消本人在该 owner 下的调用  |
| POST `/ai/calls/:id/score-preview`               | 人工审核识别值，服务端捕获版本不可提升 |
| GET `/admin/ai/calls`                            | 最近 100 笔调用时间、真实调用/数据归属账号及状态用量              |
| POST `/admin/ai/calls/:id/reconcile`             | 待核对调用结算，实际用量及原因         |

所有路径以 `/api/v1` 为前缀。真实供应商连接、模型兼容性与实际账单口径需要部署后的实测；自动测试使用假模型，不消费真实额度。
