## 一键启动行为

`python3 start.py` 默认检查依赖、按锁文件安装缺失包、自动结束 ui/server 配置端口的实际监听进程，再迁移开发库并启动。结束占用者不限本项目，权限不足或 PID 变化时停止，不提权。

`--check` 不安装、不结束进程、不启动服务；`--no-install` 和 `--no-release-ports` 可关闭相应自动行为。初次使用通过 `pnpm admin:init` 创建管理员，不提供固定默认密码。首次管理员创建和旧备份提交由用户在实际环境执行。

### 权限、额度与一致性

- 管理员本人不挂载教学工作台，不请求个人 AI；教学、文件、导出和个人 AI 的业务入口限定有效老师。代管老师沿用同一页面和目标权限，平台管理接口在代管中拒绝。管理员资料/皮肤保留独立身份上下文。
- 删除个人设置的重复皮肤页签，顶部四种主题保留。额度增加分页列表和明显添加按钮；添加/追加/扣减均弹窗操作。正额度要求完整且启用的平台配置与正常老师对象；禁用老师仅可扣减已有余额。幂等、版本、超时草稿和原账单均保留。
- 服务器入口仅注册 API 状态插件。Dexie 仅在显式 legacy 模式实例化，服务器模式误访问会报错。前端 store 是草稿/缓存；保存失败停止自动重试并保留草稿，晚响应按账号/学期代次丢弃。
- 服务端 V5 适配事务复用学生、测评、成绩、评语、课堂方案、资源等规范业务服务；预览回滚包括子事务、审计和回执。整体指纹覆盖教学数据、方案及账号配置，跨设备或其他接口的修改不会被静默覆盖。
- 导出继续使用原浏览器排版，统一下载层在下载前重新鉴权；长任务捕获开始时指纹并复验。账号/学期切换、权限失效或生成期间的数据变化会阻止旧结果下载。
- 离线旧备份转换新增原 UI 附加状态、分类名称、分项 AI 提示词、工具版式及模板素材 ID 映射。已经导入且未保留这些附加字段的数据库按现有规范数据投影；缺失的旧自定义提示词/分类名称需要原备份才能恢复，本轮未覆盖真实数据。
- 历史列拆分属于旧备份初始化步骤，服务器目录标记已迁移；后续按班级/学期与只读参照管理，不重新开放在线拆分已迁移学期。`.dexie` 全量备份/恢复/清空与错题本仍按已明确例外移除；“系统备份”服务器标签为“数据导入”。
