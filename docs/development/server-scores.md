# 服务器成绩与历史参照

日期：2026-10-07。对应 `node-sqlite-migration` 分支的成绩阶段实现。

## 使用方式

1. 登录并进入「班级与学生」，选择账号（管理员代管时）、班级和学期。
2. 打开「成绩与历史参照」，点击「测评配置」新增测评列。可以设置名称、启用状态、排序和独立满分；满分留空时沿用该学期默认满分。学期默认满分在班级学期编辑中设置。
3. 选择本期测评开始录分。名单每页 50 人，翻页保留该列草稿。空白表示未录入，`0` 表示零分；修改不会自动裁剪到满分。
4. 「保存本列修改」只提交发生变化的单元格；「取消录入」丢弃草稿。禁用、转出学生和禁用测评不能录分，已有成绩仍保留。
5. 「设置历史参照」先选择本班其他学期，再选择测评；可以从多个学期选择。表格显示历史原始分、来源满分和来源名单排名，只读参照不进入本期统计。
6. 「进入新学期」可以同时沿用名单和测评配置。沿用后生成新的测评 ID，保留原 prop、排序、启用状态与可选满分；不复制成绩，也不自动沿用历史参照。

修改默认满分或测评满分只改变满分信息，不修改原始分。允许有限原始分（含加分超过满分），接口数值范围为 -10 亿到 10 亿，不能传 NaN 或无穷大。没有成绩的学生不会凭空补零。

## 保存、冲突与离开页面

每个单元格单独具有版本。预期未录入记录的版本为 0；第一次保存后为 1，之后递增。清空成绩写入 null 并递增版本，保留数据库行，防止旧设备将清空后的记录当作从未录入而覆盖。

一次最多提交 2000 个单元格。任何单元格版本冲突，整个批次不保存，响应包含所有版本冲突的位置、服务器当前值与版本。页面保留用户草稿，不自动覆盖，不自动使用服务器版本重试。确认差异后，取消录入并刷新，再基于最新资料重新编辑。

同内容请求重试保留原 Idempotency-Key，避免响应丢失后重复提交。相同键对应不同内容返回冲突。写入、幂等回执和审计处于同一事务内。

账号/学期/页面切换会检查草稿，提交过程中禁止切换。刷新失败保留当前成绩快照；旧账号的晚到响应不能替换新账号数据。窗口重新获得焦点时，没有草稿才自动刷新；有草稿则提示手动处理，禁止静默覆盖。关闭代管资格后同步清空目标账号缓存并返回本人。

## 历史参照与统计口径

- 参照只能来自同一账号、同一长期班级的其他学期，不按班名猜测同一班级。
- 使用 studentId 关联，同名学生保持独立；缺少历史记录仍显示空值。
- 历史排名使用来源名单及来源成绩，排除来源禁用和软删除名单；来源转出学生的已有成绩仍参与历史排名。
- 排名采用竞争排名，分数相同并列，例如 1、1、3；不能用当前学期的子集名单重新排序。
- 本期统计只计算本期启用测评、未禁用且未转出的学生；零分有效，空值不计入平均分。统计包含已录数量、未录数量、平均分、最低和最高分。
- 参照关系只保存来源 ID，历史分数不会写入目标 scores 表。来源修改后再次读取可看到最新来源值。
- 被参照的测评不能删除。先在目标学期移除参照，才可以软删除来源测评；软删除保留成绩和字段名，不支持复用原 prop。
- 转班后来源保留成绩，目标名单没有成绩；不按同名测评自动复制或关联分数。

## 数据表与 API

schema v3 在 v2 上增量添加 assessments、scores、workspace_references。已有账号、班级、学生名单不清空。CLI 迁移已有数据库前按现有规则创建一致性备份。

所有接口前缀 `/api/v1`，业务访问使用真实 Bearer 登录和显式账号范围。普通账号只能操作本人；管理员代管必须启用资格。所有业务写入还需 Idempotency-Key。

| 方法       | 路径                                      | 契约                                                                                        |
| ---------- | ----------------------------------------- | ------------------------------------------------------------------------------------------- |
| GET        | /workspaces/:id/scores                    | 同一事务返回目录、名单、测评、成绩、参照与本期统计                                          |
| GET / POST | /workspaces/:id/assessments               | 读取摘要 / 创建测评，body 为 label、disabled、fullMark、sortIndex，创建可传兼容 prop        |
| PATCH      | /workspaces/:id/assessments/:assessmentId | 编辑配置，除上述字段还需 version，prop 不可修改                                             |
| DELETE     | /workspaces/:id/assessments/:assessmentId | body 携带 version，软删除，被参照时拒绝                                                     |
| PATCH      | /workspaces/:id/scores/batch              | body 为 items，每项包含 studentId、assessmentId、value（number/null）、expectedVersion      |
| GET / PUT  | /workspaces/:id/references                | 读取参照 / 整份替换参照，PUT 携带工作区 version 与 items（sourceWorkspaceId、assessmentId） |
| POST       | /workspaces/:id/promote                   | 在既有契约上增加可选 inheritAssessments，默认不沿用，UI 默认勾选                            |

测评、名单和成绩使用包含账号、工作区的复合外键。服务端同时校验 owner 和资源范围，防止跨账号、跨学期录分，以及将只读历史列当作当前测评写入。代管成绩读取和写入记录真实 actor 与目标 owner；错误明细不包含密码或账号密钥。

## 当前边界

服务器模式已接入成绩表格、统计图表与趋势、只读历史参照、Excel 预览导入和 AI 识别审核录分。人工评语、成绩通知和教学导出见 [教学导出](./server-teaching-exports.md)，数据工具见 [数据工具说明](./server-data-tools.md)。旧数据迁移采用离线预览后显式提交，不会自动读取旧浏览器教学数据；尚未迁移真实用户库。软删除没有回收站恢复 UI。

验证通过后端真实内存 SQLite / Fastify inject，以及前端适配、缓存竞态、幂等重试和组件草稿测试；没有启动实际开发服务器或宣称浏览器实机验收完成。
