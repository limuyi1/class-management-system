# 服务器评语、成绩通知与导出

日期：2026-10-07。分支：`node-sqlite-migration`。本阶段使用后端业务数据，不读取旧 Dexie 教学记录。

## 评语

在「班级与学生 → 评语与成绩通知 → 学生评语」中选择学生编辑评语，最多 5000 字。按 studentId 关联，同名学生独立保存。禁用或转出学生保留原文，只读；名单软删除后普通页面不展示其评语。

保存时携带评语版本；第一次保存预期版本为 0。遇到其他设备修改，整批不保存并返回最新内容与版本，页面保留当前草稿。可以取消编辑、刷新核对后重新填写；不会自动使用新版本覆盖服务器。

「清空」需确认，并采用软删除：数据库保留最近一次非空文本及删除时间，普通接口显示空文本；版本继续递增，防止旧设备把清空误认为从未填写。目前没有回收站或恢复按钮。

新学期和转班只沿用名单及所选配置，不复制评语。AI 生成/批量评语、评语标签及 Excel 导入已通过高级工具接入，仍须人工审核和版本校验。

## 通知设置和预览

通知单只选择本期启用测评，不把历史参照混入本期通知。保存标题、YYYY-MM-DD 日期、分数/等级模式、科目选择及等级规则，每个学期独立保存。名单、姓名、分数和评语不重复保存到通知文档里。

首次打开时默认分数模式；满分取测评独立满分或当前学期满分，默认 A 线为满分的 80%，B 线为 60%，老师可以修改并保存。规则要求 0 ≤ B 线 ≤ A 线 ≤ 满分。等级模式遇到超出规则范围的原始分，通知导出会提示调整规则或改用分数模式，不静默转换为等级。

通知设置有独立版本，不能覆盖其他设备的新版设置。科目后来被禁用或删除时，通知预览提示配置失效；先调整并保存设置，才允许生成通知。

通知预览按学生 ID 选择，同名显示 ID 尾段以便区分。默认只包含未禁用、未转出的有效学生，空成绩保持缺失，零分保持零分。可选择学生预览，使用已保存评语；没有评语显示「暂未填写评语」。

## 导出

所有导出首先重新请求 `/exports/snapshot` 并验证最新登录/代管权限，不能拿已有页面缓存替代权限检查。服务端在同一数据库事务中捕获名单、测评、原始成绩、历史关系、评语和通知设置。后续图片生成使用该次快照；选择变化或后台刷新不能混入另一账号或学期。

- **本期成绩 Excel**：学生 ID、姓名、本期启用测评及满分、评语。只含有效名单，历史参照不进入成绩表，零分与空单元格分别保存。
- **评语 Excel**：序号、学生 ID、姓名、已保存评语，不夹带成绩。
- **当前 PNG / PDF**：导出所选学生的成绩通知。
- **本批 PDF / 图片 ZIP**：按通知列表分页，每批最多 50 名学生。PDF 每人一张 A4 横向页面，可下载后打印；图片文件名包含完整学生 ID，重名不会互相覆盖。
- **停止导出**：结束后续渲染并下载已完成部分，文件名标注已完成份数。没有完成任何通知时不生成空文件。

Excel 使用服务器 Worker；通知单预览、DOM 图片捕获、PDF 和 ZIP 复用浏览器模块。没有新引入备份字体 SourceHanSerifSC-Regular.otf 的运行时用途。当前不提供旧版全部打印排版参数或系统完整备份导出。

存在未保存评语或通知设置时，导出按钮禁用；先保存或取消编辑。生成期间不能切换账号、学期或离开业务页。关闭代管或组件销毁时清空页面，未完成的生成任务不得下载已离开的账号数据。窗口恢复焦点和重新进入业务页时，无草稿才自动刷新；有草稿则提示手动处理。

## API 和存储

数据库 schema v4 增量增加 comments 和 workspace_documents；v1/v2/v3 的账号、班级、名单、测评和成绩均不重建。实际数据库迁移由 CLI 执行，本次开发没有迁移用户真实教学数据。

接口前缀为 `/api/v1`，普通账号仅本人，管理员代管仍须开启资格并指定目标。身份操作不受目标账号切换影响。

| 方法  | 路径                             | 用途                                                                                                                           |
| ----- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| GET   | /workspaces/:id/comments         | 同一事务读取名单与当前评语                                                                                                     |
| PATCH | /workspaces/:id/comments/batch   | items 包含 studentId、text、expectedVersion；空文本为软删除，写入须提供 Idempotency-Key                                        |
| PUT   | /workspaces/:id/notice           | expectedVersion 与 config，配置字段为 title、noticeDate、mode、subjects；科目包含 assessmentId、maxScore、gradeAMin、gradeBMin |
| GET   | /workspaces/:id/exports/snapshot | 捕获教学快照，同时返回通知文档版本（未保存为 0）                                                                               |

评语与名单使用包含 ownerId、workspaceId 和 studentId 的复合外键；通知保存验证所有测评属于当前账号和学期。通知文档类型固定为 score-notice，客户端不能任意上传其他文档类型或整个 Pinia store。

批量评语最多 2000 项，HTTP 请求总大小限制仍为 1 MiB，长文本客户端需拆批；当前页面逐人编辑。版本冲突整批回滚；幂等重试不重复保存。教学快照读取审计记录真实 actor、目标 owner 和工作区，日志不复制每个学生的正文。

## 验证与边界

后端覆盖评语清空保留原文/版本、重复提交、整批冲突、同名身份、跨账号、转班/升学期不复制评语、通知版本与规则、真实日期校验、导出权限和增量迁移。前端覆盖本期/历史分离、实际满分、零分/空值、同名评语、失效测评，以及权限失败不下载缓存、PDF 打包期间离开账号后不下载。

前端完整回归及构建通过；图片生成和下载流程的新增测试使用模拟浏览器依赖。没有启动开发服务器，没有宣称浏览器实机打印或导出视觉验收完成。剩余座位/值日/错题/附件/AI、复杂分析、旧业务迁移和运维灾备继续分阶段接入。

## 旧版独立通知档案

离线迁入的通知原稿保存在 `legacy-score-notice` 学期文档中，通过 `GET /workspaces/:id/legacy-notice` 按账号和学期鉴权读取。在教学页“历史成绩通知单”选择学生查看原有独立科目、分数、等级及评语，并导出当前 PNG/PDF，下载前再次鉴权。档案不覆盖本期测评或教学评语。
