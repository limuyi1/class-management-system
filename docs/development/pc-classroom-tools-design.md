# PC 班务工具扩展方案

设计与实现日期：2026-10-04。本文记录 PC 班务工具的设计规格、已落地入口与首版使用说明。

## 1. 使用原则与范围

面向纯 PC 使用：复用已有学生名单、成绩、座位和值日安排；需要外部数据时一次性导入 Excel。老师集中完成一次设置后，即可投屏、打印或批量导出，不以日常记录、持续录入为前提。

本轮确认有价值的方向：座位轮换、值日自动分配、名单打印、学习报告批量导出、通用奖状与表扬卡。考试分析打印稿保留为低优先级。随机点名与分组继续保留为候选。考场编排、学生跟进与日常表现记录不在本轮范围内。

值日已确认指“自动分配学生到岗位，排好后整学期固定”，不新增岗位轮换。

本轮已实现上述六项功能，全部沿用当前班级数据或 Excel 临时名单。随机点名与分组暂未实现。

## 2. 班级名单打印

### 2.1 入口与操作

工具中心“班级管理”增加“名单打印”。学生信息页可以增加快捷入口，传入当前班级或已选学生。

基本流程：选择模板 → 调整标题、表头和名单顺序 → 查看分页预览 → 下载 PDF 或打印。

默认读取当前班级的在班、已启用学生，沿用当前名单顺序。序号是打印序号，不展示内部 studentId。可选择部分学生、调整姓名排序，或使用已有 Excel 临时名单导入方式；同名学生按来源行或学生 ID 区分，不自动合并。

### 2.2 五个默认模板

| 模板       | 默认版式                                                       | 适用场景                         | 56 人示例分页 |
| ---------- | -------------------------------------------------------------- | -------------------------------- | ------------- |
| 精简名册   | A4 纵向，左右两栏，每栏 28 人；序号、姓名、备注                | 随手查名单、核对人数、张贴       | 1 页          |
| 收交登记   | A4 纵向，每页 28 人；序号、姓名、6 个事项格、备注              | 作业、回执、材料收交，用纸笔打勾 | 2 页          |
| 周点名表   | A4 横向，每页 28 人；序号、姓名、周一至周五各分上午/下午、备注 | 每周纸质考勤与点名               | 2 页          |
| 空白成绩表 | A4 纵向，每页 28 人；序号、姓名、6 个测评格、备注              | 纸质登记分数、课堂小测           | 2 页          |
| 签字登记   | A4 纵向，每页 20 人；序号、姓名、签字、日期、备注              | 家长会签到、资料领取、签收       | 3 页          |

样张采用 56 名虚构占位学生，仅演示布局。收交和成绩表的事项名称可以填写，也可以留空供老师手写。默认不包含家长联系方式等额外信息。

### 2.3 首版可配置项

- 标题、班级显示名称、学期显示名称、周次或日期范围。
- 表头文字、空白事项列数量、是否显示备注列。
- 纸张横向/纵向；精简名册单栏/双栏。
- 名单顺序、选中学生、行高档位（紧凑、标准、便于手写）。
- 总人数、页码以及表头重复显示。

操作界面建议采用左侧模板卡片、中间打印预览、右侧设置；切换模板即生成默认成品，不要求逐项设置。

### 2.4 打印规则

黑白线框、浅灰表头、四周默认 12 mm 页边距；表格线不小于 0.4 pt，正文建议 9-11 pt。备注与签字留白优先于装饰。名字较长时先增加姓名列宽，再适度缩小该单元格字号；不得裁切、省略姓名。

根据真实纸张尺寸、标题高度、表头高度、行高计算分页；不把全班任意缩小塞入一页。每页重复标题、列头，序号连续，姓名行不得跨页。双栏按“左栏从上到下，再右栏从上到下”的顺序排列。

周点名表默认只有周一到周五；上午/下午可合并为每日一格，以便适配不同学校习惯。签字格默认不预填签字或日期。

首版下载 PDF；打印同一份 PDF，保证预览、下载和打印的分页一致。Excel 导出可后续补充。

## 3. 座位轮换

在现有座位表工具栏增加“轮换”，沿用当前方案、过道和讲台设置。

首版提供：同列前后循环移动、同排左右循环移动；可选择方向与移动步数。前后方向以讲台朝向解释，而不是直接套画布坐标。相邻搭档整组移动可作为后续模式，遇到人数不匹配必须提示，不能静默拆散。

老师可指定固定座位/学生；特殊座位默认固定。空位默认保持空位，固定席与空位从循环队列剔除，其他学生沿剩余有效位置循环；界面明确显示跳过规则。只剩一人的队列保持原位。

生成后显示新旧对照、受影响人数和固定席。确认时保存为新方案，保留原方案；不要由预览直接改写当前座位。学生名单不完整、重复占座等情况先提示校对，不补造人员。

验收重点：学生 ID 集合不增不减、每人至多一席、固定席和空位不变、讲台上下朝向一致、取消预览后原方案不变。

## 4. 值日自动分配

沿用现有区域、岗位、按天/按周结构；一次设置岗位所需人数，生成整学期固定使用的一张表。首版默认每名学生安排一次；当前已明确的人选可锁定，仅补充其余岗位。组长继续由老师指定。

人数与岗位容量不一致时，显示未安排学生和未满岗位，不偷偷增加重复任务。生成结果先预览，再确认应用，支持手动拖动微调。已有卡片重复安排机制须明确兼容：有多个任务的学生按卡片配额参与，不按姓名去重。

沿用现有打印预览、纸张配置与导出能力，自动分配结果可直接打印。

本轮不新增每周轮换、轮次历史或值日完成记录。

## 5. 学习报告批量导出

复用现有学习报告数据构建、模板正文、预览卡片和历史参照计算。总览增加“批量导出学习报告”，一次选择学生、成绩范围与输出格式。

默认采用已有规则模板正文，不要求每位学生逐一编辑或调用 AI。可选 AI 批量生成，先展示生成数量，再生成、预览和导出；失败学生可单独重试。

首版格式：每生一张 PNG 的 ZIP，以及全班合并 PDF。文件名含班级、学期、打印序号和姓名，避免同名覆盖。PDF 按固定纸张排版：标准报告每生一页；正文超长时明确续页并保持学生边界，不截断内容。

生成时冻结当前工作区数据快照和导出范围，分批处理并及时释放图片资源；显示已完成/总数、失败名单及取消入口。部分失败时可以下载已成功文件并重试失败项。切换工作区前结束或取消当前导出。

历史成绩仍使用 useWorkspaceScores() 的只读投影，历史名次按原名单计算，缺失成绩留空；每个报告明确标注范围。学生无有效成绩时提示并允许跳过，不自动生成虚构结论。

## 6. 通用奖状与表扬卡

### 6.1 定位

工具中心增加“奖状与卡片”，支持上传背景素材后配置字段位置、批量替换内容、打印或导出。模板由老师做一次，以后换名单或内容即可复用。

现有成绩通知保持独立：它有专门的科目、等级和评语流程。新工具可以复用名单来源、素材库和导出能力，后续再将通用模板能力共享给通知单。

### 6.2 最小编辑器

- 模板底板：上传 PNG/JPG 背景，或选纯色纸张；保留原素材，设置适应/填满并预览裁切范围。
- 文字层：固定文字（标题、落款等）、批量变量文字；支持拖动、调整文本框尺寸、字号、颜色和对齐方式。
- 素材层：额外放入校徽、印章或装饰图，支持透明 PNG；可以从现有素材库选择；保存时复制图片内容到模板。
- 页面：A4 横版/竖版奖状、148 × 105 mm 表扬卡、A4 每页 4 张小卡；均可自定义尺寸。
- 显示/隐藏或锁定每层，支持复制模板。背景自带的文字保持原样，文字层按需关闭；首版不自动擦除、修复或重绘图片内容。

上传背景 → 放置字段 → 选择名单 → 逐张预览 → 批量导出。提供“空白奖状”“简洁表扬卡”“四联小卡”三个起步模板，避免用户面对空画布。

### 6.3 字段与数据来源

内置变量：姓名、班级、学期、称号、正文、日期、学校、落款。固定公共值如“进步之星”和日期只填一次。也支持从 Excel 导入姓名、称号、正文等列并一次完成映射。

选择系统学生时保持 studentId 关联；Excel 临时名单不修改系统名单或成绩。同一批次支持每人不同称号和正文。只选姓名也应能生成标准奖状，不要求录入额外资料。

可从已有成绩筛选候选学生，但展示规则和范围，名单由老师确认；首版不自动推断学生品德、课堂表现或其他没有数据的称号。

### 6.4 输出与模板保存

导出单张 PNG、批量 PNG ZIP、按原尺寸或拼版打印的 PDF。小卡拼版保持卡片长宽比，提供裁切线和卡片间距，预览明确每页张数与总页数。

模板存储背景/素材快照、纸张尺寸、文字层和变量绑定，不固化具体学生姓名。字段位置用模板坐标保存，按输出尺寸统一缩放；预览与导出共用布局计算，长文本有明确溢出提示，不静默裁切。

模板全局共用；班级与学期作为渲染时的变量。批量名单和临时 Excel 行只用于本次任务，除非明确保存为草稿。模板已通过全局 tools 记录纳入完整备份。保存的是图片快照，删除素材库原图不会破坏已保存模板。

## 7. 考试分析打印稿（低优先级）

复用已有测评统计，选择本期成绩列后生成简洁 A4 分析稿，包含范围、满分、有效人数、缺失人数、均分、及格率、优秀率、分数段及可选学生名单。

只有存在可比较的有效成绩时展示进退步；历史参照明确标识，不混入本期班级指标。空白成绩只能称为“未录入/无成绩”，不能推断为缺考。跨卷难度差异不能仅靠分数变化判定。

## 9. 首版入口与使用说明

| 功能           | 入口                                         | 首版行为                                                                                                                           |
| -------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 名单打印       | 工具 → 班级管理 → 名单打印                   | 五种模板；选择学生、姓名排序、Excel 临时名单、事项表头、行高、横竖版、备注、双栏；分页 PDF                                         |
| 座位轮换       | 座位表 → 轮换                                | 前后/左右循环、步数、固定学生；跳过空位与雅座；预览后另存新方案                                                                    |
| 值日自动分配   | 值日表 → 自动分配                            | 每格所需人数、保留已安排学生、未分配/未满岗位提示；另存固定安排，可拖拽微调                                                        |
| 批量学习报告   | 工具 → 教学反馈 → 批量学习报告；总览快捷入口 | 选择成绩范围、默认规则正文、逐人编辑、可选 AI；生成进度、停止/继续/重试、PNG ZIP、合并 A4 PDF                                      |
| 奖状与表扬卡   | 工具 → 教学反馈 → 奖状与表扬卡               | 默认奖状/表扬卡/空白素材模板；背景上传或素材库、文字/图片层、变量、拖动/缩放、显隐/锁定、保存/复制模板；PNG、ZIP、原尺寸或四联 PDF |
| 考试分析打印稿 | 工具 → 教学反馈 → 考试分析打印稿             | 本期单列原始分统计、分数段、有效/缺失人数、可选学生明细、分页 PDF                                                                  |

批量报告跳过所选范围内无有效成绩的学生；0 分是有效成绩。历史参照采用只读百分制投影，历史名次和人数仍按原名单计算。每名学生在 PDF 中从新页开始，长报告按宽度缩放后自动续页，保留完整正文；续页按图像切片，可能在段落或表格内部换页。报告生成或奖状导出期间阻止本页面切换班级/学期。

奖状公共字段本批次填写一次，Excel 同名列优先；系统班级与学期来自当前工作区。自定义变量使用 `{{列名}}`。未填写变量、文本超出文本框、图层超出纸张时预览提示，导出会列出对应学生失败原因，不静默裁切。素材背景原有文字不会自动擦除。模板保存布局、变量和图片快照，不保存本批次学生名单及公共字段值。

排版、变量替换、批量队列分别拆成工具函数、页面组合式函数和画布/设置面板，关键逻辑均有中文注释。固定学生与值日岗位容量沿现有工作区快照保存；全局模板沿现有 tools 表持久化并纳入完整备份。
