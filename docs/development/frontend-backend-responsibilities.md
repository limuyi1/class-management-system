# 前后端职责与导出实施调整

2026-10-07 根据用户讨论更新。后端是权限、数据和业务规则的权威；按输出形式决定渲染位置，不把所有旧工具简单搬到服务器。

| 工作                                     | 归属及理由                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| 数据隔离、版本、软删除、幂等、审计       | 后端统一执行，不能依赖浏览器判断                                             |
| 成绩统计、历史排名、分析数据投影         | 后端读取一致快照并计算，前端显示图表，统一查询/导出口径                      |
| Excel 导入、批量校验                     | 后端校验、预览与事务提交；前端选文件、列映射、展示错误及确认                 |
| AI 提示词构建、模型调用、Key、额度       | 后端执行，前端提供场景输入、进度和结果确认                                   |
| 纯数据 Excel/CSV 导出                    | 已由后端生成，按 owner 与筛选条件读取快照，不接受前端提交数据作为导出权威    |
| 通知单、座位表、值日表等打印预览         | 前端保留排版和浏览器打印能力，使用后端授权的一致快照                         |
| DOM 转 PNG、所见即所得 PDF、复杂试卷排版 | 当前保留前端渲染，以延续现有版式、字体和交互；统一模板确定后再评估服务器渲染 |
| 拖拽、裁剪、旋转和草稿编辑               | 前端交互，图片结果与版本化草稿保存后端                                       |
| 主题、设备字号、临时选择                 | 前端设备偏好；可跨设备同步的业务版式及配置另存账号设置                       |

## 导出当前状态和后续顺序

成绩、评语 Excel/CSV 已由服务端 Worker 生成；Excel 校验预览及提交、分析统计、学习报告模型、AI 生成也已接入后端。图片/PDF、课堂工具和试卷继续由浏览器渲染授权快照；生成结束前重新校验权限并检查账号/工作区代次。具体限制见 [服务器数据工具](./server-data-tools.md)。

图像和 PDF 保留浏览器方案直到模板和字体复用验收通过，避免为了少量用户额外常驻无头浏览器。大批量或耗时导出实测后再决定是否使用异步任务；若引入任务，须绑定 actor/owner/版本快照、限制并发、支持取消与过期清理，任务结果下载再鉴权。

不新增对备份大字体的运行时依赖。第一阶段收尾统一验收导出内容、打印分页、账号隔离、撤权、重复请求与代表性数据量下的内存和延迟。
