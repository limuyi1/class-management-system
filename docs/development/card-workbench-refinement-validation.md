# 学习报告与成品模板制作修正

日期：2026-10-04。使用现有通知作为视觉参考，在独立的生产预览地址和虚拟学生数据上验证。

## 实现

- 修复 `AppEChart.vue` 的 Vue 导入落在 `<script setup>` 外的问题，新增真实组件挂载测试，覆盖默认画布、SVG、绘制完成标记、更新和销毁。
- 奖状、表扬卡默认进入成品制作。模板选择采用 DOM 缩略预览，基础填写区仅展示模板实际使用的公共变量。
- 拖动、图层属性、背景和自定义素材放到高级设置；基础制作不显示手柄，点击文字不会跳入图层编辑。
- 内置成品复用原通知的真实纸张、花纹、四角装饰及配色。素材作为静态资源复用缓存，在显式保存时内嵌到模板，支持独立备份和跨版本复用。
- 保存公共文案时排除姓名、班级、学期、日期和未使用字段。逐人姓名、成绩和 Excel 自定义字段仍由名单提供。
- 常用 PDF、成品预览保留在底栏，四联拼版、单人 PNG 和批量 ZIP 收入导出选项。新区域使用 Element Plus 滚动组件。
- 页面、业务组合函数、模板选择、公共内容、高级设置和素材边框分文件维护，并补充中文注释。

## 左侧操作栏调整（2026-10-04）

根据左栏拥挤的反馈，使用生产构建在 1280 × 720 视口检查并调整，虚拟名单与临时 Excel 均使用独立预览地址。

- 顶部集中放置当前模板、更换模板、选择学生人数和高级编辑。移除左栏的制作/名单/高级设置三页签以及常驻模板卡。
- 左栏按屏幕宽度扩至 340–400px，只显示公共文案。标题、称号并排，正文全宽并按内容增加高度；署名与日期默认折叠。
- 成品模板和已存模板统一在选择弹窗内展示，现有通知素材的转换入口也移入弹窗。
