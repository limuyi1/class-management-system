# 服务器导入、分析、打印及业务文档

2026-10-07。入口为「班级与学生 → 分析、导入与高级工具」。服务器是教学数据权威，工具不读取旧 Dexie 业务 Store。

## Excel 导入和导出

上传 XLS/XLSX，最大 8 MB；解析在最多两个 Worker 中进行，15 秒超时，限制工作表、2000 行和 200 列。XLSX ZIP 每个条目展开最多 16 MB，累计 64 MB，不支持加密/分卷/超大 ZIP；不执行单元格公式或宏。前端只指定表头行、姓名/学生 ID/成绩/评语列，原始解析数据保存在绑定 actor、owner、workspace 的 24 小时预览中。

成绩/评语以学生 ID 优先匹配，没有 ID 时要求姓名唯一；同名、转出、禁用、重复行及无效科目报错，不能猜测合并。零分保留，空值为未录入，按测评或学期满分检查。预览记录单元格/评语版本，确认时整批事务提交，有一项冲突全部回滚。成绩与评语分开确认。

名单模式逐行创建长期身份，不按姓名合并；显式历史 ID 必须属于该账号且不在本期。导入不替换或清空现有名单，重复请求不重复新增。预览后名单/学期版本变化须重新预览。

成绩、评语 Excel/CSV 由后端生成，使用一致教学快照和有效本期名单。历史参照不混入成绩导出，评语导出不夹带成绩。CSV 对可能解释为公式的文本添加前缀，Excel 把文本写成字符串。下载有鉴权、no-store，不把 Token 写到 URL，也不公开临时目录；转换完成后再次检查权限及工作区。

## 分析和打印

统计、分数区间、缺失数量、学生均分与排名由服务端计算，图表由浏览器展示。历史趋势按 studentId 连接，来源排名使用原学期名单，缺失不补零。本期统计排除历史参照。

名单打印沿用精简名册、收交登记、点名、空白成绩表及签字登记版式。测评打印统计取服务器本期数据。名单核对按同名出现次数匹配，支持班级与外部名单、两份外部名单比较。

奖状、表扬卡支持内置或保存模板。模板编辑可增加文字、修改字体/坐标/大小、拖拽图层并保存到账号设置。模板软删除保留原内容。业务字体、默认纸张、AI 默认要求、模板及版式存账号，主题仍是操作者设备偏好。

学习报告的成绩、均分、排名、历史参照及正文模板由后端计算。可选择分析范围、人工编辑/保存正文或使用本人 AI 生成。正文独立版本，并记录所依据的成绩版本和范围；成绩或范围变化后标记需复核，保存审核前不能批量导出旧结论。一次最多 50 人，服务端一次事务捕获报告快照；PDF 长正文自动续页，每人另起新页，支持 ZIP 和停止后的部分下载。

图片/PDF 继续复用浏览器渲染，避免初期常驻无头浏览器。每批最多 50 页/人，生成后再鉴权、检查账号/学期代次；撤权或切换后不下载旧目标结果。实际纸张、系统字体和打印机效果仍需桌面浏览器实测。

## 素材与排版

素材支持分页、排序、重命名、旋转/裁剪和软删除；处理后的 PNG 保持素材身份，以版本检查提交。试卷草稿保存纸张设置及位置，引用账号内不可变图片快照。原素材后来修改、排序或删除不会破坏已经保存的草稿；新引用仍须核验素材版本。打开失败释放临时 URL，改名及位置变动纳入草稿保护。

## API

| 路径                                                 | 用途                                    |
| ---------------------------------------------------- | --------------------------------------- |
| POST `/workspaces/:id/imports/file`                  | 上传二进制 Excel，返回预览 ID 和解析行  |
| POST `/imports/:id/preview`，`/imports/:id/commit`   | 列映射、校验及事务确认                  |
| GET `/workspaces/:id/export?kind=scores&format=xlsx` | 成绩/评语，xlsx/csv                     |
| GET `/workspaces/:id/analysis`，`/exam-print`        | 学情及测评打印模型                      |
| POST `/workspaces/:id/compare-names`                 | 名单次数匹配                            |
| GET/PUT `/workspaces/:id/reports/:studentId`         | 报告模型和审核正文                      |
| POST `/workspaces/:id/reports/preview`               | 1–50 人一致报告快照                     |
| GET `/resources`，PUT/DELETE `/resources/:kind/:id`  | tags/paper/settings，版本、幂等、软删除 |
| GET `/papers/:id/items/:itemId/content`              | 草稿不可变素材，鉴权及审计              |
| DELETE `/workspaces/:id`                             | 软删本学期或该班全部学期，保留教学记录  |

均以 `/api/v1` 为前缀。登录后 GET `/api/v1/openapi.json` 可查询实际路由及请求 JSON Schema；响应 DTO 见 `packages/shared`。身份/密钥接口拒绝代管，业务接口携带目标 owner，由后端再次核对权限。

学习报告保存同时携带服务端生成的 `sourceVersion`（报告事实摘要），历史来源成绩、排名、标签等改变后必须重新读取审核；仅有本期工作区版本相同不能绕过检查。
