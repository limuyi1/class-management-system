# 打印工具 DOM 渲染改造计划

状态：已实施并完成工程检查与浏览器回归。验收记录见 [DOM 打印验证记录](./dom-print-validation.md)。

## 1. 改造目标

编辑和日常预览直接展示真实 DOM；文字、表格、图层及图表随数据更新。成品预览也优先展示隐藏编辑控件的同一份 DOM；仅在用户明确查看导出图片或执行 PNG / ZIP / PDF 导出时生成图片。放大清晰度是本次核心验收项。

同一份数据、分页结果和 DOM 组件同时用于屏幕预览与离屏导出。纸张尺寸、字体和排版共用，预览缩放仅影响屏幕显示。继续使用 Element Plus 滚动组件、独立设置区及常驻操作栏。

## 3. 目标流程和交互

1. 选择名单、版式及内容后，工作台展示 DOM 纸张，直接切换学生和页码。
2. 修改文字、字号、颜色、行距或位置时，更新对应 DOM 图层；不启动截图、不刷新整张图片。
3. 点击文字或素材选择图层，属性页与选中框联动；拖动和缩放即时更新 DOM。普通查看状态允许选中文字；拖动只在选中图层的编辑状态进行，避免整张纸阻止文本选择。
4. “整页适应 / 适应宽度 / 100%”沿用当前工具栏；设置区、预览区、图层列表及成品预览继续使用 `el-scrollbar`。
5. “成品预览”展示同一份 DOM 纸张并隐藏选框、标签和手柄，保持放大后的文字清晰。另提供主动触发的“查看导出图片”，按当前学生或当前页生成 PNG，在 Element Plus 弹窗内查看；显示图片倍率与生成版本，默认不超过原像素尺寸展示，编辑后标记为需重新生成。
6. 批量导出沿用进度、停止和部分结果下载。图片素材本身仍用 `<img>`，表扬卡上的姓名、正文及表格保持真实 DOM。

## 4. 分阶段实施

### 第一阶段：DOM 渲染与导出的共享边界

- 建立统一的纸张 DOM 接口：获取纸张节点、纸张毫米尺寸及渲染就绪状态。
- 复用当前缩放 / 滚动容器；纸张换算、字体尺寸、坐标与屏幕缩放分离。普通卡片继续保存毫米位置和 pt 字号，转换模板保留已有原始像素基准，避免通知素材被重新排版。
- 复用 `renderDomPngBlob` 和通知专用截图逻辑，补齐字体、图片、DOM 布局及图表就绪等待。生成图片仅从导出操作调用。
- 复用同一纸张组件挂载导出副本，导出前冻结名单、内容和设置；副本位于原尺寸离屏容器，不能 `display: none`。
- 分离导出用的纸张内容和编辑用的选框、拖动手柄、图层标签，确保这些控件不会进入文件。

### 第二阶段：奖状、表扬卡和通知素材

- 将 `CardCanvas.vue` 拆为 DOM 纸张组件、图层交互组件和拖动组合式函数。
- 普通模板：文字用真实文本节点与 CSS，素材按当前 contain / cover 规则展示；字体、字距、行距、描边、阴影和换行由共用样式函数提供。
- 通知素材：把现有素材树重建与字段绑定从截图函数拆出，挂载为工作台中的真实 DOM。切换模板时重建节点；切换学生或修改属性时更新对应节点，拖动期间不反复销毁整棵素材树。
- 溢出检测读取 DOM 的实际文本范围和纸张边界，随字体加载和图层尺寸更新；未填写的变量明确提示。
- 普通文字在失去焦点或提交时写回模板表达式；编辑 `{{姓名}}` 等变量时保留表达式，不能把当前学生的显示值保存进模板。先沿用属性面板编辑，不引入复杂的富文本编辑器。
- PNG / ZIP / PDF 从同一 DOM 纸张导出。移除编辑链路中的 `toDataURL()`、整页 PNG 和异步图片渲染队列。
- 保持已保存的普通模板及 `scene.version = 1` 模板可读取，原通知的分组结构和变量保持兼容。移除不再使用的手写 Canvas 绘字实现，PDF 拼版继续复用。

### 第三阶段：名单打印和考试分析

- 名单：继续使用 `paginateRoster()` 的学生排序、连续编号、纸张方向与双栏规则。用 `<table>` / `<colgroup>` / `<thead>` / `<tbody>` 渲染五种名册，标题、页脚和空白填写栏均为 DOM。
- 考试分析：保留 `buildExamPrintAnalysis()`；分页函数只返回摘要页和明细页的数据。摘要使用 DOM 统计项、条形分布及备注线，明细使用 DOM 表格。
- 当前页按需挂载；导出按同一页模型逐页挂载、等待和截图，不在设置变化时提前生成所有页的 Canvas。
- 表格边框、行高、标题区域与页脚预算共用。标题换行等超出预算时，按实际 DOM 测量重新分页或明确提示；不通过压缩整页掩盖文本溢出，不截断表格行。

### 第四阶段：学习报告和原通知回归

- 学习报告继续使用现有 DOM 卡片；打印场景启用 SVG 图表，等待图表完成后截图。
- 长报告继续沿用已经验证的 PDF 续页机制，保证完整正文和逐名学生新页；本次不扩大为新的富文本或浏览器原生打印分页系统。
- 原成绩通知保留 DOM 布局、科目规则、手写字体与导出效果；共享导出准备逻辑时，以既有真实素材实验重新对照。
- 检查通知与奖状合并入口、旧链接重定向、导出停止和未保存提示，避免改造影响之前完成的交互。

## 5. 代码拆分建议

按职责落在现有目录，避免把页面和渲染器继续写成大文件：

- `components/print-workbench/`：纸张容器、离屏导出宿主、最终成品预览弹窗。
- `views/tools/components/cards/`：卡片 DOM 纸张、普通图层、素材树、交互选框。
- `views/tools/components/roster/`：名单纸张与名单表格。
- `views/tools/components/exam/`：统计摘要、成绩明细及纸张组件。
- `views/tools/composables/`：图层拖动、按页导出、成品预览状态。
- `utils/print-template/`：素材节点构建、字段绑定、样式换算及 DOM 溢出检测。
- `types/`：共用纸张接口与考试页面模型。

组件名在实施时按现有规范确定；工具函数和组合式函数补齐中文 JSDoc，兼容数据字段补充中文说明。无需新增依赖，不启用备用大字体。

## 6. 验收标准

### 渲染和编辑

- 文字、表格在浏览器检查中是真实 DOM，可选中；没有用于替代整张纸内容的 PNG。素材图片和主动打开的成品图不受此限制。
- 修改文字、拖动和切换学生期间不调用整页截图、`toBlob()` 或 `toDataURL()`。
- 100%、200%、400% 放大时，文字、表格线条和 SVG 图表保持清晰，不放大缓存的整页位图；预览缩放范围按此验收补齐。拖动坐标在各种缩放比例下准确，字体加载完成后不出现位置跳动。
- 素材图片保持宽高比，放大或改变文本框大小不能拉伸校徽、花纹及照片。背景 cover 的裁切与 contain 的完整显示按明确设置执行。
- 通知素材的标题、姓名、成绩与评语仍为独立节点，不保存真实学生数据到模板。

### 文件和兼容

- 预览与导出使用同一套 DOM 组件和页面数据，选框 / 标签 / 手柄不出现在 PNG 或 PDF 中。
- 三科目、五科目真实 0 分、八科目长标题、十二科目缺失值、长评语、更换学生均回归。
- 保留相同环境下的原通知视觉基准和像素对照，逐项记录差异；不把缩放后的截图作为原尺寸基准。
- 旧普通模板、旧素材模板、上传 / 替换素材、保存重开及完整备份恢复通过验证。
- 名单连续编号无重复 / 缺失，表格分页无切行；考试分析本期统计不混入历史参照。
- PNG、ZIP、合并 PDF、奖状四联 PDF、报告长文续页和停止后部分结果均实际下载验证。

### 窗口和工程验证

- 覆盖 1024×768、1366×768、1920×1080、1280×600，以及相当于 125% 缩放的逻辑视口。
- 设置和预览可滚动至底部，主要操作保持可见，全部相关滚动使用 Element Plus。
- 按阶段运行必要组件 / 分页 / 导出测试，最终通过类型检查、Lint、完整测试和生产构建。

## 7. 实施边界

本次针对打印工具的编辑和预览架构。PNG 是有固定像素尺寸的文件，超过其原像素尺寸放大仍可能模糊，不能通过提高默认导出倍率承诺无限清晰。原始位图素材同样受自身分辨率限制；检查有效尺寸，优先复用已有高清或 SVG 素材，避免拉伸，不把位图伪装为矢量。PDF 仍允许嵌入高分辨率图片，不承诺矢量 / 可编辑文字 PDF；工作台和成品预览的 DOM 清晰度不受这一路导出限制。上传图片不会自动转成可编辑文字。现有试卷图片排版、座位业务拖动等其他画布不因本次改造被整体重写。

建议按上述四阶段作为一次完整改造交付；第一阶段建立共用边界后，优先处理奖状和通知素材，再完成名单、考试分析及全链路回归。
