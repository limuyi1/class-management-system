# DOM 打印改造与验证记录

日期：2026-10-04。已完成 [实施计划](./dom-print-rendering-plan.md)。测试使用生产构建和独立浏览器资料，虚构名单与通知数据没有写入用户的实际班级数据库。

## 实现

- 奖状编辑由 `CardPaper` 持续挂载真实文字／图片节点；选框、标签及拖动手柄由 `CardCanvas` 单独维护。输入、切换学生和拖动没有整页截图。原通知素材保持 `scene.version = 1`、原字体和节点结构；就地更新从原始样式计算，撤销不会累积位移。
- 名单与考试分析只计算页模型，当前页使用 `RosterPaper` / `ExamPaper` 的 DOM 表格和统计条形。字体、标题、正文、页脚预算共用；超出预算时提示并阻止截断导出。
- 学习报告图表启用 ECharts SVGRenderer，其他图表默认仍使用 CanvasRenderer。导出等待字体、图片解码、图表完成事件和两帧布局。
- `PrintProductPreview` 默认展示同一 DOM；点击“查看导出图片”才生成 PNG，显示分辨率、倍率、生成时间和版本失效状态。纸张内容不包含编辑手柄，预览支持 100%、200%、400%。设置、纸张和弹窗都使用 Element Plus 滚动组件。
- 图片／PDF 导出使用原尺寸离屏副本，冻结数据、版式及页序，逐页生成并释放节点。名单／考试分析提供进度和停止，已成功页面仍可下载。长报告保留续页及逐名学生新页规则。
- 不新增依赖，不启用备用大字体，不修改工作区持久化字段或备份格式。新增工具、拖动函数和关键兼容处理均附中文注释。

PNG、ZIP、普通 PDF、四联 PDF、长报告续页及停止后的 PDF 均实际下载。用 PDF-lib 检查页数和 A4 尺寸，用 Pillow 检查 PNG 与 ZIP 图片尺寸，并查看实际纸张与工作台截图。修复了真实导出发现的空背景问题：无源 `<img>` 会让截图库读取当前 HTML，现已移除空背景节点并过滤空图片。

## 原通知素材对照

独立对照页分别调用正式的原通知导出与通用模板导出，比较未经缩放的 RGBA 像素：

| 场景 | 尺寸 | 最终复核不同像素 |
| --- | --- | --- |
| 三科等级 | 1448×1086 | 0 |
| 五科分数，含真实 0 分 | 1448×1086 | 0 |
| 八科、长标题与姓名 | 1448×1126 | 0 |
| 十二科，含缺失值 | 1448×1086 | 0 |
| 长评语 | 1448×1113 | 0 |
| 已捕获模板更换学生 | 1448×1086 | 0 |

一次复跑出现透明校徽边缘像素差异，八科场景单独重新加载复核后为 0；文字、布局和尺寸没有差异。这些结果仅代表当前浏览器和字体环境，不承诺跨环境字形或透明图片抗锯齿逐像素一致。之前的实际产品 2 倍装饰边缘对照及首轮实验仍保留在 [通知真实素材验证](./notice-material-validation.md)。

生成物位于被 Git 忽略的 `output/playwright/`，包括测试脚本、PNG / ZIP / PDF、`dom-pdf-validation.json` 和素材对照数据。
