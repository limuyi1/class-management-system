# 班务系统总览页 2.0 重构开发规范

1. 页面布局结构 (Layout Design)
   页面采用 “顶部指标 + 底部双栏” 的结构，解决信息眼花缭乱的问题。
* Top KPI Section (100% 宽度): 聚合数据概览，让老师一眼看到学期全局结论。
* Left Section (70% 宽度 - A区): ECharts 学期趋势与成绩分布图。
* Right Section (30% 宽度 - B区): “学生观察站”。这是临界生和异动学生的主要展示阵地。

2. 核心模块：B 区 “学生观察站” (Focus Center)
   这是重构的重点。使用 el-tabs 切换，将学生分类过滤，减少单页信息量。
   Tab 1: 重点预警 (重点展示临界生)
   在这个 Tab 下，临界生和低分生分两组垂直排列。
* 临界生展示样式 (Critical Student Item):
    * 判定算法： 最近一次分数在 [45, 70] 之间，且历史成绩中既有及格记录也有不及格记录。
    * UI 组成：
        1. 基础信息： 学生头像 + 姓名。
        2. 状态图标： 名字后显示 ⚖️ (平衡木图标)。
        3. 名次变动： 显示 ↓ 3 (红色) 或 ↑ 2 (绿色) 标签。
        4. 微缩趋势图 (Sparkline): 在名字下方展示一个迷你的 SVG 折线图，显示最近三次单元的成绩走势（例如：58 -> 65 -> 62）。
        5. 背景视觉： 卡片背景色设为极浅的黄色 (#FFFBE6)。
* 持续低分生展示样式:
    * 判定算法： 连续两次单元成绩 < 60。
    * UI 组成： 名字后显示 🚨 图标，卡片背景色设为极浅的红色 (#FFF1F0)。
      Tab 2: 异动分析
* 下滑者 (Downstream): 排名下降 $> 10$ 名的学生，名字后显示 📉。
* 黑马 (Breakthrough): 排名上升 $> 10$ 名的学生，名字后显示 🚀。
  Tab 3: 荣誉榜单
* 定海神针: 所有单元均在 90 分以上的学生，显示 🔥。
* 勋章逻辑: 名字后展示 🥇 (进入前五名次数 $\ge 3$) 或 🥈 (进入前五名次数 1-2)。

3. A 区：ECharts 视觉降噪规范
   图表采用堆叠柱状图，每个单元一根柱子，柱子内部严格按以下 5 色段 划分：
* [90 - 100]： #52C41A (深绿) - 卓越
* [80 - 89]： #B7EB8F (浅绿) - 良好
* [70 - 79]： #1890FF (品牌蓝) - 中等
* [60 - 69]： #FAAD14 (明黄) - 临界/及格
* [ < 60 ]： #F5222D (警示红) - 不及格
* 交互： 折线图显示班级平均分走势。点击柱状图的某个颜色块，右侧 B 区自动过滤出该分段的学生名单。


4. 顶部 KPI 栏：多单元聚合指标
   展示全学期的累计数据，而非单次成绩：
* 综合平均分： 全学期所有成绩的算术平均值。
* 及格率稳定性： 全学期平均及格率（下方显示波动百分比）。
* 需关注学生总数： 去重统计。全学期累计进入过“不及格”或“临界”状态的总人数。
* AI 诊断 / 模板结论（主要是学情分析）： 若未配置 AI，则显示逻辑生成的结论：“本学期已完成 {n} 个单元，及格边缘学生共 {m} 人，第 {x} 单元波动最大。”
    * 所以这块儿还需要配置生成的提示词，在设置中进行配置。
